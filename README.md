# animation-geodesic-orbit
A Python visualization project that creates an animated geodesic-like orbital motion using Matplotlib. The simulation displays a moving celestial body with a smooth orbital trail inspired by spacetime curvature and orbital mechanics.

This project creates:
- A smooth animated orbit
- A moving celestial object
- Continuous orbital trail visualization
- A clean spacetime-inspired simulation

---

## Preview

The animation displays a particle moving along a curved orbital trajectory similar to geodesic motion around a massive body.

---

## Features

- Smooth real-time animation
- Orbit trail rendering
- Simple physics-inspired visualization
- Beginner-friendly Python code
- Lightweight and easy to modify

## Technologies Used

- Python
